## Problem
App.swift (391 lines) is a god object: AppDelegate handles hotkey wiring, sidecar
lifecycle, audio capture, dictation state machine, typewriter driving, text injection
orchestration, WAV recording, and menu bar UI.

## Proposed structure

### DictationSession (new)
Owns the dictation state machine — one session per hotkey toggle cycle:
- `start()` → captures target, starts audio, begins sidecar session
- `stop()` → stops audio, waits for final result, commits text
- Owns: typewriter, injection method, audio level forwarding
- Emits events: `partialText(String)`, `finalText(String)`, `modeResolved(AX|clipboard)`
- Testable without UI: inject mock sidecar + mock text injector

### AppDelegate (slimmed)
Pure wiring:
- Menu bar setup
- Hotkey → `dictationSession.start()` / `dictationSession.stop()`
- Observe session events → update MicPanel + status icon
- Sidecar lifecycle (start on launch, shutdown on quit)

### Other extractions
- `WAVWriter` — static helper for PCM→WAV encoding (currently inline in saveRecording)
- Move `yuwpLog` into a tiny `Log.swift`

## Benefits
- DictationSession is testable (mock sidecar, mock injector)
- Clear separation: session logic vs UI vs infrastructure
- Easier to add features (configurable panel position, multiple session types)

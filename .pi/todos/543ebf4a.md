## Problem
The transcript bubble (clipboard fallback mode) positions above the caret/cursor, which
can be invasive — covering the input area in terminals.

## Decision (from user testing)
**Follow the mouse cursor** — user explicitly said "the best place to display the bubble
is actually just to follow my [cursor]." This makes the most sense because:
- In clipboard-fallback mode, the text isn't going into any specific field yet
- The user's attention is already near the mouse
- No fixed position to block content

## Implementation
- Track `NSEvent.mouseLocation` during recording
- Update panel position in the `driveTypewriterDisplay` loop or on a timer
- Keep `clampToScreen` for edge clamping
- AX-verified mode: compact dot still tracks the text caret (unchanged)

## Notes
- macOS native dictation uses a small fixed indicator near the menu bar
- Panel already has `isMovableByWindowBackground` for manual drag

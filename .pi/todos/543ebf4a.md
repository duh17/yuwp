## Problem
The transcript bubble (clipboard fallback mode) positions above the caret/cursor, which
can be invasive — covering the input area in terminals.

## Options to explore
1. **Follow mouse** — panel tracks mouse position during recording
2. **Pinned position** — configurable screen corner (top-right, bottom-center, etc.)
3. **Configurable via menu** — let user pick: near-cursor, pinned corner, follow-mouse
4. **Auto-detect** — use near-cursor for AX apps, pinned corner for clipboard-fallback apps

## Current state
- AX-verified apps: compact waveform dot that tracks the caret (good)
- Clipboard-fallback apps: full bubble panel above caret (invasive)
- Panel has `clampToScreen` but position can still block the input area

## Notes
- macOS native dictation uses a small fixed indicator near the menu bar
- Consider allowing drag-to-reposition (panel already has `isMovableByWindowBackground`)
